HTTP ingest

curl -sS -X POST http://127.0.0.1:8080/ingest/raw \
  -H "Content-Type: application/json" \
  -d '{"sender":"you@example.com","subject":"VPN issue","body":"Cannot connect from home."}'

List tickets

curl -sS http://127.0.0.1:8080/tickets | python3 -m json.tool | head -20
Use your cluster gateway Route URL instead of 127.0.0.1:8080 on OpenShift. Add X-Ingest-Key when the hardened overlay is enabled.
